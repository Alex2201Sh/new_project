# Что демонстрирует этот пример:
1. Интерфейс Soundable:
- Объявляет метод makeSound()
- Реализуется классами Dog и Cat по-разному
2. Абстрактный класс Animal:
- Содержит поля (name, age) и конструктор
- Имеет абстрактный метод eat() (без реализации)
- Имеет обычный метод sleep() (с реализацией)
3. Наследование:
- Dog и Cat наследуются от Animal
- Используют super() для вызова конструктора родителя
- Реализуют абстрактный метод eat()
4. Создание объектов:
- Dog myDog = new Dog(...)
- Cat myCat = new Cat(...)
5. Вызов методов:
- Методы родительского класса (sleep())
- Собственные методы классов (fetch(), purr())
- Методы интерфейса (makeSound())
6. Полиморфизм:
- Обработка разных объектов через интерфейс Soundable
- Обработка разных объектов через абстрактный класс Animal
